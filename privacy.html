AgentFlow privacy policy

Last updated: 28 October 2026

What data is accessed

AgentFlow requests two read-only Google scopes: yt-analytics.readonly and youtube.readonly. It reads the authorising channel's title, video list and analytics reports (views, watch time, average view duration, audience retention).

How it is used

The data is used only to measure how the channel's own videos perform and to improve future videos. It is never sold, shared with third parties or used for advertising.

Storage

The OAuth refresh token is kept in the owner's local macOS Keychain and a private configuration file on the owner's own computer. Analytics numbers are stored in a private database on the owner's machines. Nothing is published.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. AgentFlow's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
